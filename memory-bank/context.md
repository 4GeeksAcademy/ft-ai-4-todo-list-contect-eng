# Project Context

This file captures the current product direction for the todo application. The project is intentionally small and user-focused, centered on a dependable task management experience with local persistence and simple interactions.

## Core features
- Add a new task with a title and optional reminder metadata
- Mark a task as complete or active
- Delete a task from the list
- Update an existing task title, priority, or reminder
- Assign a priority level to each task (low, medium, high)
- Set a reminder date and time for a specific task

## Current direction
- A single-page todo app with a clear task list and filtering
- Local storage for persistence across refreshes
- Minimal architecture to keep maintenance simple and predictable
- Documentation-first workflow to support future iteration
- Vanilla HTML, CSS, and JavaScript only, with no external libraries or frameworks
