# Project Rules

1. When you update the architecture, update the architecture.md file with a brief, concise explanation of the change and the location of supporting information.
2. When you make a change, log it in the progress.md file.
3. Keep the project context document aligned with the current direction of the app.
4. Maintain a clear separation between architecture, progress, and context documentation.

- memory-bank/architecture.md
- memory-bank/progress.md
- memory-bank/context.md
